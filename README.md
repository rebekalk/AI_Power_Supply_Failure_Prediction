# AI-Based Power Supply Failure Prediction System

## Project Description
This project uses machine learning to predict whether a
power supply is operating normally or showing abnormal
conditions based on electrical readings.

## Technologies Used
- Python
- Machine Learning
- Scikit-learn
- Streamlit
- Pandas

## Input Parameters
- Input Voltage
- Output Voltage
- Current
- Temperature

## Features
- Interactive web application
- Predicts normal or abnormal conditions
- Simple user interface

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Run the application:

   streamlit run app.py

## Dataset
The project uses synthetic data for educational purposes.

## Disclaimer
Predictions are not validated for real power supply equipment.
